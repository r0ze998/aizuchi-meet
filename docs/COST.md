# 実行時費用と、有料 API を使う前の確認事項

更新: 2026-10-17。**この時点で有料 API は一度も呼んでいません**（中継は mock のみで動かしました）。

## 開発枠と実行時の料金は別

- いま開発に使っている Claude Code（Fable 5.1）の利用枠は、このアプリの実行時には使われません。
- 完成したアプリの候補生成は、中継プロセスが持つ **Anthropic Console の API キー**（従量課金・前払いクレジット）で課金されます。Claude Pro/Max や Claude Code の枠で API が無料になるとは想定しません。
- 音声認識（Chrome Web Speech API）と翻訳（Chrome Translator API）は無料です（前者はサーバーモードだと音声が Google に送られます。docs/PRIVACY.md）。

## 1 回の候補生成で送るもの（概算トークン）

| 内容 | 概算 | 備考 |
|---|---|---|
| システムプロンプト（ルール） | 約 900 tok | 毎回同一。キャッシュ対象 |
| 登録情報（プロフィール） | 約 800 tok | 会議中はほぼ不変。キャッシュ対象 |
| 直近の会話（最大 10 ターン）＋最新の発話 | 約 360 tok | 毎回変化 |
| 出力（要約 + 候補 3 つ + 短い思考） | 約 300–400 tok | effort=low |

登録情報を増やせばその分だけ入力が増えます（上限 7,000 文字で切り詰め）。

## 30 分 / 60 分会議の推定（候補生成）

前提: 相手の質問 15–25 件、暫定候補 10–15 回、言い直し・追加 5–8 回 → **約 45 リクエスト / 30 分**（90 / 60 分）。価格は Anthropic 公式 API（入力 / 出力、$/百万トークン）: Opus 5.5 $4 / $20、Sonnet 5.5 $2 / $10、Haiku 5.5 $0.10 / $0.50。

| モデル | 1 リクエスト | 30 分 | 60 分 | 備考 |
|---|---|---|---|---|
| claude-opus-5-5（既定） | 約 $0.016（キャッシュ無し）/ 約 $0.010（キャッシュ有り） | **約 $0.5–0.7** | **約 $1.0–1.5** | 品質優先。キャッシュはプレフィックス長が最小長に満たないと効かない |
| claude-sonnet-5-5 | 約 $0.008 | 約 $0.35 | 約 $0.7 | |
| claude-haiku-5-5 | 約 $0.0004 | **約 $0.02** | **約 $0.03** | 最も低遅延・低費用。日本語の自然さは要確認 |

任意: 翻訳も中継経由（Translator API を使わない場合）にすると、120 セグメント / 30 分で Opus 約 $0.2、Haiku 約 $0.005 が加わります。既定は端末内翻訳なので $0 です。

**モデル自体の応答遅延は未計測です**（モック中継での計測のみ。docs/LATENCY.md）。目標の「質問確定から 1〜2 秒で最初の候補」は、Opus 5.5 では思考分を含めると厳しい可能性があり、その場合は Haiku 5.5 へ切り替える判断材料として実測を提示します。

## 上限（中継が強制）

- `MAX_SESSION_USD`（既定 1.00）: 中継プロセスの累計推定費用がこれを超えると 402 を返し、パネルに「費用上限に達した」と表示して候補生成を止めます。Opus で 60 分なら 2.00 を推奨。
- `MAX_REQ_PER_MIN`（既定 30）: 超過分は 429。
- 費用は API が返す `usage` から中継が計算した推定値です。請求額は Console で確認してください。

## 有料 API を使う前に、あなたに確認したいこと

次を了承いただけたら、`relay/.env` を作ってください（キーはチャットに貼らず、ファイルに直接）。

1. **送信先**: `api.anthropic.com`（Anthropic）。中継は 127.0.0.1 からのみ呼びます。
2. **送るデータ**: 登録情報（全項目）、直近 10 ターンの英語の文字起こし、最新の発話、「こう言いたい」の日本語。**音声は送りません。** 表示しただけの候補は送らず、「これを話した」と押したものだけ文脈に入れます。
3. **保持**: Anthropic API の既定ではプロンプトと出力は保持されません（Covered Models を除く。Opus 5.5 / Haiku 5.5 は該当しません）。学習には使われません。詳細は docs/PRIVACY.md。
4. **モデルと推定費用**: 既定 `claude-opus-5-5`（30 分 約 $0.5–0.7、60 分 約 $1.0–1.5）。低費用なら `claude-haiku-5-5`（60 分 約 $0.03）。
5. **上限**: `MAX_SESSION_USD`（提案: Opus 2.00 / Haiku 0.20）、`MAX_REQ_PER_MIN` 30。
6. Opus 5.5 / Sonnet 5.5 では、安全分類器が応答を拒否した場合に別モデルで続行するサーバー側フォールバック（`fallbacks: "default"`）を有効にしています。不要なら `REPLY_FALLBACKS=0`。
