# 遅延の計測

更新: 2026-10-24（数値は 2026-10-24 のフルラン）。計測はすべて **専用 Chrome（Chrome for Testing 155）＋テスト用合成音声（macOS `say`）＋モック中継** での値です。**実際の Meet 通話と実際の Claude API の遅延は含みません。** これは検証目標の確認であって、達成の保証ではありません。

## 計測方法

`extension/lib/pipeline.js` が各区間を記録し、サイドパネル下部に p50 / p95 を表示します（「JSON をコピー」で書き出し）。ハーネス `test/harness/e2e-speech.mjs` は、再生ページ側の再生開始・終了時刻を基準にした実測（下表「再生基準」）も別に取ります。

- **p50 / p95**: 最近傍順位法。
- 音声は 16 kHz モノラルの合成音声 12 本（`test/fixtures/audio/`）。

## 結果（1 回のフルラン、シナリオ 12 本）

### パイプライン内部の計測

| 区間 | n | p50 | p95 | 備考 |
|---|---|---|---|---|
| 音声取得→認識（発話開始→最初の途中結果） | 12 | **493 ms** | 758 ms | Web Speech（Google サーバーモード） |
| 音声取得→認識（発話終了→確定） | 12 | **749 ms** | 852 ms | 最後に音が出てから確定テキストまで |
| 認識→翻訳（途中訳） | 28 | 472 ms | 473 ms | **モック翻訳**（下記注） |
| 認識→翻訳（確定訳） | 10 | 121 ms | 127 ms | **モック翻訳** |
| 質問の確定→最初の候補 | 11 | **353 ms** | 355 ms | **モック中継**（設定 350 ms 遅延。実 Claude ではない） |
| 質問（暫定）→最初の候補 | 13 | 354 ms | 364 ms | 同上 |
| 候補生成の完了まで | 24 | 504 ms | 657 ms | モック中継 |
| 言い直し→結果 | 1 | 354 ms | 354 ms | モック中継 |

### 再生基準（ページの再生時刻を基準にした実測）

| 区間 | n | p50 | p95 |
|---|---|---|---|
| 再生開始→最初の途中結果 | 11 | 647 ms | 4742 ms |
| 再生終了→最後の確定 | 11 | 592 ms | 708 ms |
| 質問の確定→最初の候補 | 10 | 353 ms | 355 ms |
| 質問（暫定）→最初の候補 | 6 | 354 ms | 364 ms |

p95 の 4742 ms は「無音→短い発話→無音→発話」のシナリオ（q12）で、最初の無音区間ぶん最初の結果が遅れた値です。発話が始まってからの追従は p50 500〜700 ms です。

## 目標との比較（検証目標。保証ではない）

- 目標「日本語訳が数秒程度の遅れで追従」: 認識の途中結果が p50 約 0.5 秒、翻訳はモックで +0.1〜0.5 秒。**端末内翻訳（Translator API）の実時間は未計測**（下記注）。
- 目標「質問が安定してから最初の短い候補が 1〜2 秒程度」: モック中継では p50 約 0.35 秒。**実 Claude の生成遅延は未計測**で、Opus 5.5 は思考を伴うため 1〜2 秒に収まらない可能性があります。低遅延を優先する場合は `claude-haiku-5-5` を選べます（docs/COST.md）。

## 重要な注記（何が「本物」で何が「モック」か）

- **音声認識**: 本物（Chrome Web Speech API、Google サーバーモード）。この環境では端末内（オンデバイス）認識の言語パックが「ダウンロード中」のままだったため、サーバーモードで計測しました。
- **翻訳**: この環境では Translator API の en→ja モデルが「downloadable（未ダウンロード完了）」で、計測時間内に準備が終わらなかったため、E2E は**モック翻訳**にフォールバックしています。したがって上表の翻訳区間は**モックの値**です。Translator API が端末内に存在すること自体は確認済み（`test/harness/probe-builtin-ai.mjs`）。実時間は、設定画面「翻訳モデルを準備」でモデルを落としてから再計測が必要です（未実施）。
- **候補生成**: **モック中継**（規則ベース、設定 350 ms 遅延）。実 Claude の遅延・費用は未計測（docs/COST.md）。
- 古い生成の中止（`AbortController`）、短い待機（デバウンス）、音声・翻訳キューの上限、取りこぼし表示は実装・テスト済みです。認識テキスト 1 文字ごとに候補 API を呼ぶことはしていません（質問の確定・暫定のタイミングでのみ生成）。
